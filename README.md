# Хапа Shop 😼

Telegram-магазин цифровых товаров: бот + мини-апп. Маскот — кот-барыга Хапа.
Каталог, баланс, автовыдача со склада, автоцена от закупки в USDT, защита от продаж в минус, двухуровневая рефка с рангами и топом.

## Запуск на ПК

```
npm install
npm start
```

Или `start.bat` (перезапускается при падении), `start-hidden.vbs` — то же без окна.
Настройки — в `.env`. При `TUNNEL=1` поднимается бесплатный HTTPS-туннель, адрес мини-аппки подставится сам.

**Один токен — один запущенный бот.** Если этим токеном уже пользуется другой проект, будет ошибка 409 Conflict.

## Рефка

- Ранги по числу друзей, которые хоть раз что-то купили: **Котёнок 10% → Барыга 12% (от 3) → Хапуга 15% (от 10) → Босс котов 20% (от 30)**.
- Вторая линия: 3% с покупок друзей твоих друзей.
- Новичку по ссылке — скидка 10% на первую покупку.
- Начисляется **с покупок, а не с пополнений** — нельзя накрутить пополнением.
- Всё вместе (скидка + рефка) никогда не уводит заказ в минус: рефка не больше `ref_cap`% (по умолчанию 50%) прибыли заказа, скидка — не ниже `min_profit`.
- Топ рефоводов за 30 дней в мини-аппке и в боте (`/ref`). Приз для топа: `/prize Топ-1 месяца получает 1000 ₽`.

## Закупка и автоцена

- `/setcost ID 16.7 usdt` — закупка товара (или `rub`).
- `/auto ID on` — цена считается сама: `(закупка × курс × (1 + p2p%)) / (1 − комиссия − наценка)`, но с прибылью не ниже `min_profit`; округляется до числа на 9.
- Курс USDT берётся с CoinGecko каждые 15 минут (`/rate 92.5` — задать вручную, `/rate auto` — вернуть авто).
- Цена поменялась → обновляется в боте и мини-аппке, админу приходит список, а если задан `NEWS_CHAT_ID` — пост в канал.
- Если закупка подорожала, а цена ещё старая, покупка блокируется («цена обновляется»), админу приходит алерт.
- Осталось мало на складе (`low_stock`) — алерт «пора докупить».
- `/cfg` — все настройки, `/set fee_pct 5` — изменить.

## Оплата

- **CryptoBot** — `CRYPTOPAY_TOKEN` (@CryptoBot → Crypto Pay → Create App). Зачисляется автоматически.
- **Ручная** — `MANUAL_PAY=текст инструкции` (например, перевод USDT на твой Bybit UID). Покупатель жмёт «Я оплатил» и шлёт скрин, тебе приходит заявка: `/pay номер` — зачислить, `/nopay номер` — отклонить.

## Админка (`/admin` в боте)

Товары: `/plist`, `/addprod`, `/addunl`, `/addstock ID`, `/cleardemo`, `/setprice`, `/setdesc`, `/hide`, `/show`, `/hit`, `/seticon`, `/setimg`, `/sethero`.
Деньги: `/pay`, `/nopay`, `/addbal`. Прочее: `/orders`, `/done`, `/stats`, `/say`, `/prize`.

Стартовый каталог — **примеры**: цены и закупки поправь под себя, DEMO-позиции склада покупателям не продаются (`/cleardemo` удаляет их).

## Баннеры бота

`node scripts/banners.js` — перерисовывает `assets/*.png` с котом Хапой из `scripts/banners.html` (нужен установленный Chrome).
